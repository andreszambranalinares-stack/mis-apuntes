# Mis Apuntes

Apuntes visuales e interactivos para estudiar: cada tema con su contenido completo,
mapas cerebrales que se iluminan, experimentos que se pueden jugar, tarjetas de repaso con
repetición espaciada y tests tipo examen.

**Temario actual:** Atención, percepción y memoria · Bloque I (Atención) · Tema 3:
*Enfoques recientes sobre la atención y su relación con la consciencia*.

## Qué hay dentro
- 16 secciones con todo el contenido del tema, organizadas en el menú lateral.
- Más de 30 interactivos: atlas cerebral con redes y rutas animadas, simulador de detección
  de señales, reloj de Mackworth, tarea de Posner, búsqueda visual, Stroop, Go/No-Go,
  heminegligencia, modelo de Norman y Shallice, ignición del espacio de trabajo global…
- Tarjetas con sistema Leitner (el progreso se guarda en el navegador).
- Test con explicación de cada respuesta.
- Buscador (`Ctrl K`), modo claro/oscuro, y diseño adaptado a móvil, iPad y ordenador.

## Uso en local
```
python -m http.server 5173
```
y abrir <http://localhost:5173>.
